# feedback-loop-ai — brand

The organisation's mark. Not Brokkr's — Brokkr keeps its own anvil in
[`brokkr/assets`](https://github.com/feedback-loop-ai/brokkr/tree/main/assets).
The two share a palette and a stroke idiom so they read as family.

## The mark — "stage loop"

A cycle with its stages marked on the rail, and the feedback arrow closing it
back to the node it left. That is the organisation's thesis drawn once:
feedback loops — the software delivery cycle first, but feedback loops in
general — in an AI-native world.

| file | use |
|---|---|
| `avatar.svg` | source of truth; 512 viewBox, no animation |
| `avatar.png` | 1024², opaque — the GitHub organisation avatar |

## Palette

| role | hex |
|---|---|
| ground | `#12101a` |
| signal (the loop, the arrow) | `#45e08c` |
| node (where the signal returns) | `#7c5cff` |

Flat fills, one stroke weight, round joins, no gradients. Same as Brokkr.

## Rules

- The mark sits on the ground colour. Do not place it on white or on a photo.
- Do not add the wordmark inside the avatar; at 20–32 px it is illegible.
- Brokkr's anvil is the product mark; this loop is the organisation's. Do not swap them.
